# API-тесты учебного сервиса Яндекс Самокат

Тесты API сервиса: создание курьера, авторизация, создание заказа, список заказов.

1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать: `venv\Scripts\activate`
3. Установить зависимости: `pip install -r requirements.txt`

Особенности стенда
- Поле `firstName` при создании курьера необязательно: без него сервис отвечает 201.
- Логин без пароля возвращает 504 (gateway timeout) — в тестах это учтено как ошибка.
